# flask

Описание

Проект реализует локальное взаимодействие клиента с сервером в целях изучения.
+ Для работы базы данных использован докер контейнер котрый собирается из docker-compose.
+ Для создания и удаления базы данных на этапе отладки структуры может быть использован файл recreate_db.sh.
+ Для функционирования запускается server_board.py с правами группы администратора, затем client.py с набором запросов из браузера.
